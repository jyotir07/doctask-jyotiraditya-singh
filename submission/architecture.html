Movement 3 — Stay alive

An update costs like an update

Fact cache keyed (doc_sha256, extractor_version). Re-ingesting known bytes re-extracts nothing and re-embeds nothing. A rename never buys a second extraction.

Untouched is provably untouched

Entry identity is (vendor, field) — deliberately excluding the value, so an amendment updates an entry instead of appending beside it. Each entry renders from itself alone, so non-modification is byte equality, not assertion.

Foundation

Durable step journal — deterministic step ids, outcome + tokens + timing recorded per step. Autocommit, because a journal write buffered inside an open transaction would be rolled back by the very crash it exists to survive. Cost is derived from the journal, so a crashed run still reports what it spent.
PostgreSQL 16 + pgvector — runs, steps, documents, facts, entries, deliverables, chunks. Chunks carry the char offsets they were cut from, so a citation made while reading a retrieved passage still verifies against the original document.

No LangGraph: its checkpointer re-executes a node interrupted mid-flight and re-pays for the model call inside it. The unit that must not repeat is the provider call, not the node — so the journal does that job, and the graph layer would add a dependency without adding a capability.
